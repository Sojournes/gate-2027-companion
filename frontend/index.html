☁️ Deploy Your GATE Companion for Free (24/7 Cloud Access)
Zero Cost Hosting

This application is built as a unified Node.js + Express REST API + Static SPA Frontend with a pre-configured render.yaml and Dockerfile so you can deploy both Frontend and Backend together in 2 minutes for free!

Option 1: Render.com (Recommended — 100% Free Web Service)
  1. Push this folder (GATE_Application) to a GitHub repository.
  2. Go to render.com → New + → Web Service → Connect your GitHub repo.
  3. Set Build Command: npm install and Start Command: npm start (or use Blueprints with the included render.yaml).
  4. Click Deploy Web Service — your live URL will be ready in ~60 seconds!
Option 2: Koyeb / Fly.io / HuggingFace Spaces (Docker Free Tier)

A production Dockerfile is included in the project root. You can deploy it directly to Koyeb Free Tier, Fly.io, or a HuggingFace Docker Space (16GB RAM free, never sleeps!).
