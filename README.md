# GATE 2027 ECE & FDE Study Companion

A full-stack study planner, test series tracker, spaced-repetition quiz/flashcard engine, and anti-burnout scheduler tailored for **GATE 2027 Electronics & Communication Engineering (ECE)** + **Ed Donner's 21.5h FDE Udemy Course**.

## Key Features
1. **88-Day Intelligent Day-by-Day Planner (`10 Nov 2026` → `6 Feb 2027`)**:
   - **Weekdays (Off Work 6–7 PM)**: Study `19:00 – 00:00` with a built-in **45m Guilt-Free Gaming & Recharge Break (`21:05 – 21:50`)** + optional **12:00 AM – 1:30 AM Late-Night Push Flex Window**.
   - **Weekends (All Day Free)**: Structured `09:00 – 00:00` blocks with a **90m Weekend Gaming Session (`16:15 – 17:45`)**, lunch/nap break, test series arena, and Udemy FDE module slot.
   - **Mid-Week Breather**: Wednesdays schedule only 1 lecture + problem solving so you never burn out.
   - **20-Day (~3-Week) Pre-Exam Buffer (`17 Jan 2027` → `5 Feb 2027`)**: All 11 ECE subjects (164 lectures at `2x–3x` speed) and all 22 Udemy FDE modules finish by **16 Jan 2027**, leaving nearly 3 full weeks before the **6 Feb 2027 GATE Exam** for Full-Length GBG Mocks, PYQs, and final revision.
2. **11 GATE ECE Subjects (PW 2027 Batch + PW 2026 YouTube Fallback)**:
   - Tracks all 164 lectures across Network Theory, Signal System, Control System, Digital Electronics, Engineering Mathematics, General Aptitude, Analog Electronics, EMFT, EDC, Communication System, and COA.
   - Automatically maps subjects available in your PW 2027 Batch vs subjects using the **PW GATE Wallah 2026 YouTube Playlist** fallback, with one-click source toggling.
3. **All 56 PW GATE 2027 ECE Tests**:
   - **21 TWT** (Topicwise Tests), **10 SWT** (Subjectwise Tests), **8 MST** (Multi-Subject Tests including Level-up), **5 GATE PYQ Tests** (2022–2026), and **12 GBG** (Full-Length GATE Before GATE Mocks).
4. **Spaced Repetition Active Recall Engine (SM-2 Flashcards + GATE ECE Quiz)**:
   - Automatically schedules `+3d`, `+7d`, `+14d`, and `+25d` active recall reviews after each subject finishes, with an interactive 3D Flashcard Deck and GATE ECE Multiple-Choice Quiz Arena.
5. **Ed Donner FDE Udemy Course Tracker (21.5 Hours / 22 Modules)** & **Built-in Pomodoro Studio**.

## Running Locally
```bash
npm install
npm start
```
Then open `http://localhost:5000` in your browser.
